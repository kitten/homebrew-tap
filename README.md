# kitten/tap

Homebrew formulae for my tools, installed from their release binaries.

```sh
brew install kitten/tap/linn
brew install kitten/tap/git-porter
brew install kitten/tap/pinentry-touchid
```

| Formula | Platforms |
| --- | --- |
| [linn](https://github.com/kitten/linn) | macOS 14+ (Apple silicon), Linux (arm64, x86_64) |
| [git-porter](https://github.com/kitten/git-porter) | macOS 14+ (Apple silicon), Linux (arm64, x86_64) |
| [pinentry-touchid](https://github.com/kitten/pinentry-touchid) | macOS 14+ (Apple silicon) |
